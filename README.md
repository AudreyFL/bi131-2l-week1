# BI131-2L Week 1 Reproducibility Activity
## Repository
- Project and repository name: `bi131-2l-week1`
## Objective
At the end of this laboratory activity, students should be able to:
1. Organize a small bioinformatics project using a consistent directory structure.
2. Retrieve and validate a small protein FASTA dataset for an assigned species.
3. Apply previously learned Linux commands to inspect the FASTA file and generate reproducible result files.
4. Record the analysis in a shell script that can regenerate the required outputs.
5. Use Git and GitHub to preserve meaningful changes and submit a traceable repository.
6. Run the workflow in Docker, document data provenance, and declare any AI assistance used.
